# Submission checklist (manual items)

- [ ] **Add AMD_BASE_URL and AMD_MODEL to `.env`**, then run `python check_amd.py` until it prints OK (~5 min)
- [ ] Run `streamlit run app.py` locally, click Diagnose and ask one chat question (~5 min)
- [ ] **Rotate your API key if you shared the screenshot anywhere public** (~2 min)
- [ ] Create the public GitHub repo and push (commands in the reply) (~5 min)
- [ ] Deploy on Streamlit Community Cloud and add secrets (~10 min); test the public URL
- [ ] Record the 90-second demo video from `pitch_script.md` and upload (YouTube unlisted / Loom) (~20 min)
- [ ] Build slides from `slides.md` (Google Slides or PowerPoint), export PDF (~15 min)
- [ ] Cover image: use `cover.png` or generate one from `cover_image_prompt.txt` (~3 min)
- [ ] On lablab.ai: paste title, short + long description, tags; add GitHub URL, demo URL, video, slides, cover; **click Submit** (~10 min)
